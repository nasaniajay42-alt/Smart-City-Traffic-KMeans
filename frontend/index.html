Automated Behavioral Customer Segmentation using K-Means Clustering

This system applies unsupervised machine learning to partition retail customer cohorts into distinct behavioral profiles. StandardScaler normalizes income and spending scores, the Elbow Method and Silhouette Analysis optimize cluster cohesion, and empirical centroid profiling automatically derives actionable marketing personas.

Academic ML Workflow
1
Standardization: Distance calculation in K-Means is Euclidean; raw feature scaling prevents income ($15k–$137k) from dominating spending score (1–100).
2
Optimal K Selection: The Elbow heuristic (WCSS curve bend) combined with Silhouette Coefficient peak determines natural data boundaries.
3
Empirical Dynamic Profiling: Unscaled centroid statistics dynamically title and interpret segments (e.g. High-Value Champions vs Budget Savers).
